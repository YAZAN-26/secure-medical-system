# Secure Medical Records System

A secure web-based application built with Python and Flask for managing and protecting medical records with strict role-based access control (RBAC) for doctors and patients, alongside a robust security audit logging system.

## Features
- Role-Based Access Control (Admin, Doctor, Patient).
- Secure file upload and encryption handling.
- Audit logging for tracking critical system actions.

## Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS
